DARBAR LASSI — CREAMY MOTION WEBSITE
Extract this package and open index.html in Chrome.
Keep the assets folder beside index.html.
The website uses the supplied Darbar lassi and chocolate cold coco GIF animations.
To activate WhatsApp ordering, replace ADD_SHOP_NUMBER in index.html with the official number including country code (digits only).
The Maps links search each area; replace them with verified branch pin URLs before publishing.
The product menu and prices should be checked against the current branch menu before publishing.
